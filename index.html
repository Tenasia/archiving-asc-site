Archiving ASC

A private, self-hosted media archiving tool.

Archiving ASC saves images posted in selected WhatsApp group chats to the operator's own Google Drive, sorts them into folders, and logs each one in a Google Sheet. An internal dashboard lets the operator review images that couldn't be sorted automatically.

How it uses Google

  • Google Drive: creates an archive folder and its subfolders, uploads images into them, and moves images between them when the operator re-files one. It uses the drive.file permission, which only allows access to files and folders the app itself created.
  • Google Sheets: writes one row per archived image to a log spreadsheet the app created.

The app isn't offered to the public. It runs on the operator's own server and is used only by the operator's Google account.
